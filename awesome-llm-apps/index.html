Mais de 100 agentes de IA prontos pra você clonar, mudar e colocar no ar

O Awesome LLM Apps é um repositório grátis no GitHub com mais de 100 agentes de IA, skills de agente e apps de RAG, todos de código aberto e com licença Apache-2.0. Cada app vem com o código inteiro funcionando. Você pega o mais parecido com a sua ideia e adapta.

01Pra que serve

  • Rodar um agente pronto em poucos comandos, como o AI Travel Agent, que monta roteiro de viagem dia a dia.
  • Começar um projeto a partir de um app que já funciona, em vez de uma tela em branco.
  • Explorar por categoria: agentes iniciantes e avançados, times de agentes, agentes de voz, agentes MCP, RAG, apps com memória, Chat with X, fine-tuning e cursos rápidos de frameworks.
  • Usar com Claude, Gemini, GPT, DeepSeek, Llama, Qwen e outros modelos abertos. Alguns apps rodam 100% no seu computador, sem chave de API.
  • Licença Apache-2.0: dá pra fazer fork, colocar no ar e vender.

02O que você precisa

  • Git (pro git clone)
  • Python com pip (pro pip install)
  • Pro agente de viagem: chave da OpenAI e chave da SerpAPI
  • Ou, pra rodar sem chave da OpenAI: Ollama instalado e rodando

03Passo a passo

  1. Crie as duas chaves que o agente de viagem usa. A primeira é da OpenAI, em platform.openai.com. A segunda é da SerpAPI, que faz as buscas na web:
    https://serpapi.com/
  2. Abra o terminal (no Windows, o PowerShell) e baixe o repositório inteiro:
    git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
  3. Entre na pasta do agente de viagem:
    cd awesome-llm-apps/starter_ai_agents/ai_travel_agent
  4. Instale o que o app precisa:
    pip install -r requirements.txt
  5. Rode o app. Ele abre no navegador com o título AI Travel Planner. Cole a chave da OpenAI no campo "Enter OpenAI API Key to access GPT-4o" e a da SerpAPI em "Enter Serp API Key for Search functionality". Depois diga o destino e quantos dias, e clique em Generate Itinerary. No fim dá pra baixar o roteiro como calendário (.ics).
    streamlit run travel_agent.py
  6. Não quer pagar API? Com o Ollama instalado e rodando, use a versão local. Nada sai do seu computador e não precisa da chave da OpenAI.
    streamlit run local_travel_agent.py

05Antes de usar

  • O repositório é grátis, mas o agente de viagem usa o GPT-4o da OpenAI e a SerpAPI. Cada roteiro gasta créditos nas duas. Se quiser custo zero, use a versão local com Ollama.
  • Os "30 segundos" contam a partir de quando você já tem Git, Python e as chaves. O README não diz qual versão do Python usar. Se o pip install der erro, o problema costuma ser a versão do Python ou uma biblioteca já instalada.
  • Cada app tem a sua pasta, o seu requirements.txt e as suas chaves. Leia o README da pasta antes de rodar.
  • Nunca cole a sua chave de API no código nem em print pra internet. Quem pega a sua chave gasta no seu cartão.
  • Licença Apache-2.0: pode usar, mudar e vender, mas mantenha o arquivo LICENSE e os avisos de autoria no seu fork.

Resumindo: clona o repositório, entra na pasta do app, instala e roda. Depois escolhe o app mais parecido com a sua ideia e adapta pra ser seu.
