Peça pro Claude Code checar se o seu app cumpre a LGPD

O LGPD Skills é um complemento grátis e de código aberto pro Claude Code. Ele ensina o Claude a revisar o seu app com as regras da LGPD (a lei brasileira de dados pessoais) e a apontar o que falta: dado coletado sem necessidade, serviço de fora que recebe dados, pedido do cliente pra ver ou apagar os dados, vazamento e mais.

01Pra que serve

  • Fazer uma auditoria completa de LGPD no seu projeto. Começa com uma pergunta só: é um projeto novo, um sistema que já está no ar, uma mistura dos dois, ou já houve um vazamento?
  • Achar coleta exagerada no cadastro, como telefone obrigatório que o app nem usa.
  • Listar cada serviço de fora (analítico, pagamento, e-mail…) como compartilhamento de dado pessoal.
  • Montar o caminho pro cliente ver, corrigir ou apagar os próprios dados, com prazo de resposta de 15 dias corridos e confirmação dupla antes de apagar a conta.
  • Conferir se os registros do servidor (os logs) mostram dado pessoal completo. O certo é aparecer mascarado.
  • Em caso de vazamento, guiar o aviso à ANPD (o órgão que fiscaliza a LGPD), que tem prazo de 3 dias úteis.
  • Tudo o que ele produz fica salvo numa pasta .lgpd dentro do seu projeto: situação geral, mapa dos dados, lista do que falta, política de privacidade e mais.

02O que você precisa

  • Claude Code instalado (também funciona no Codex, Gemini CLI, Cursor e OpenCode)
  • Um projeto seu aberto no Claude Code
  • Nenhuma outra configuração além de instalar

03Passo a passo

  1. Abra o Claude Code dentro da pasta do seu projeto.
  2. Adicione o repositório como loja de complementos (marketplace de plugins). Copie e cole este comando na conversa do Claude Code:
    /plugin marketplace add goul4rt/lgpd-skills
  3. Agora instale o LGPD Skills:
    /plugin install lgpd-skills@lgpd-skills
  4. Peça a auditoria em português. O Claude vai perguntar qual cenário descreve o seu projeto (A: novo, B: já no ar, C: misto, D: houve um vazamento). Responda com a letra.
    veja como estamos de LGPD
  5. Acompanhe as pausas. Antes de cada documento importante (política de privacidade, relatório de riscos, aviso à ANPD), ele para e pergunta se é pra continuar, ajustar ou pausar pra você revisar com calma. Os resultados ficam na pasta .lgpd do projeto.

05Antes de usar

  • Não é consultoria jurídica: o próprio projeto avisa isso. Aviso à ANPD, cláusula de contrato e texto de política de privacidade devem passar por um advogado ou pelo encarregado de dados da empresa.
  • É grátis e de código aberto (licença MIT): pode usar até em projeto comercial. O que você paga é só o seu plano do Claude Code.
  • Os exemplos foram pensados pra apps web e de celular comuns. Se o seu app usa outras tecnologias, as regras continuam valendo, mas os exemplos de código podem precisar de ajuste.
  • A auditoria completa é longa e para várias vezes pedindo a sua resposta. Reserve um tempo e leia o que ele gerou antes de aprovar.
  • No OpenCode os complementos não ligam sozinhos: é preciso chamar cada um pelo nome.

Resumindo: dois comandos no Claude Code, um "veja como estamos de LGPD" e ele te mostra o que o seu app precisa corrigir antes de virar problema.
