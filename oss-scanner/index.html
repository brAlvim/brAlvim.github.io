A Anthropic caça falhas no seu projeto open source, de graça

O OSS Scanner é um serviço da Anthropic: os modelos mais fortes dela varrem projetos open source atrás de falhas de segurança, de tempos em tempos, e mandam o que acharem por e-mail. A Anthropic paga o custo.

01Pra que serve

  • Receber relatórios de falhas de segurança no seu projeto sem pagar uma auditoria.
  • Cada relatório traz uma prova de como a falha é explorada e, quando dá, uma sugestão de correção.
  • A análise roda isolada: o projeto é compilado numa máquina virtual e examinado sem acesso à internet.

02O que você precisa

  • Ser mantenedor de um projeto open source
  • Conta no GitHub
  • Um Dockerfile que compila o projeto
  • Um e-mail de contato (fica público)

03Passo a passo

  1. Faça um fork do repositório oficial de inscrição.
    https://github.com/anthropics/oss-scanner
  2. Crie a pasta do seu projeto: projects/<nome-do-projeto>.
  3. Dentro dela, crie o project.yaml a partir do modelo (templates/project.yaml). O mínimo é isto:
    repo: https://github.com/voce/seu-projeto
primary_contact: seguranca@seudominio.com
dockerfile: .oss-scanner/Dockerfile
  4. Escreva um Dockerfile que instala todas as dependências e compila o projeto. Ele pode ficar no seu repositório (recomendado) ou na mesma pasta do project.yaml. Tudo que os testes precisam tem que ser baixado nessa etapa: a análise roda sem internet.
  5. Opcional: um threat_model.md explicando o que é sensível no projeto. Ajuda o scanner a focar no que importa.
  6. Abra o pull request. Os relatórios chegam no primary_contact.

05Antes de usar

  • Os relatórios são gerados pelo modelo e não passam por revisão humana. Confirme cada falha antes de corrigir ou divulgar.
  • Os e-mails do project.yaml ficam públicos: use um endereço de segurança, não o pessoal.
  • O foco são projetos open source críticos. A inscrição depende de aprovação do pull request.
  • O uso segue os termos do serviço: red.anthropic.com/oss-scanner/terms.

Resumindo: um pull request com dois arquivos, e o seu projeto passa a ser auditado pelos modelos mais fortes da Anthropic, sem custo.
