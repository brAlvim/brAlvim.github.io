Transforme o Claude Code num estúdio de vídeo completo

O Open Montage é grátis e de código aberto. Ele coloca uma equipe de produção dentro do seu assistente de IA: você descreve o vídeo e ele pesquisa, escreve o roteiro, busca imagens e cenas grátis, edita e entrega o vídeo pronto, pedindo sua aprovação em cada decisão.

01Pra que serve

  • Fazer um vídeo inteiro com um pedido só: pesquisa, roteiro, visuais, narração, edição e montagem final.
  • Vários formatos: vídeo explicativo, animação, demonstração de tela, trailer de cinema, documentário com cenas reais, podcast virando vídeo e mais.
  • Mandar um vídeo que você gosta (YouTube, Shorts, Reels, TikTok) e pedir algo no mesmo estilo sobre o seu assunto.
  • Sem pagar nada extra: narração que roda no seu computador e cenas de acervos grátis (Archive.org, NASA, Wikimedia Commons).
  • Funciona com Claude Code, Cursor, Copilot, Windsurf e Codex.

02O que você precisa

  • Python 3.10 ou mais novo (python.org)
  • Node.js 18 ou mais novo (nodejs.org)
  • FFmpeg (programa grátis que mexe com vídeo e áudio)
  • Git (pra baixar o projeto)
  • Um assistente de IA: Claude Code, Cursor, Copilot, Windsurf ou Codex

03Passo a passo

  1. Instale o Python 3.10+, o Node.js 18+ e o FFmpeg. Se já tiver, pule esse passo.
  2. Abra o terminal (no Windows, o PowerShell) e baixe o projeto pra uma pasta no seu computador:
    git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
  3. No Windows, rode estas duas linhas, uma de cada vez. Elas instalam tudo e criam o arquivo de configurações. Se o npm install der o erro ERR_INVALID_ARG_TYPE, troque por npx --yes npm install.
    py -3 -m venv .venv; .\.venv\Scripts\Activate.ps1; python -m pip install -r requirements.txt
cd remotion-composer; npm install; cd ..; python -m pip install piper-tts; Copy-Item .env.example .env
  4. No Mac ou no Linux, é um comando só:
    make setup
  5. Abra a pasta OpenMontage no Claude Code (ou no assistente que você usa) e descreva o vídeo que você quer, como nos pedidos abaixo. Ele vai propor ideias, mostrar o custo estimado e pedir sua aprovação antes de cada etapa.
  6. Quer ver o andamento da produção num quadro? Rode este comando na pasta do projeto:
    python -m backlot open

05Antes de usar

  • Sem nenhuma chave paga, os visuais vêm de cenas e imagens de acervos grátis. Pra gerar vídeo com IA, ou você liga serviços pagos (opcionais, configurados no arquivo .env) ou usa uma placa de vídeo boa no seu computador.
  • Com serviços pagos ligados, o próprio projeto dá exemplos: um vídeo animado de 60 segundos com narração saiu por cerca de US$ 1,33. Ele mostra a estimativa antes e, de fábrica, pede aprovação pra gasto acima de US$ 0,50 e trava o total em US$ 10.
  • Pexels, Unsplash e Pixabay (bancos de imagem) dão chave grátis de desenvolvedor: vale cadastrar pra ter mais opção de cenas.
  • O Open Montage é grátis, mas o assistente de IA (Claude Code, Cursor...) é o que você já usa, com o plano que você já tem.
  • Licença AGPLv3: pode usar à vontade nos seus vídeos, mas se você modificar o código e oferecer como serviço pra outras pessoas, tem que abrir o seu código também.

Resumindo: baixa o projeto, roda a instalação, abre no Claude Code e descreve o vídeo em português. Ele faz o resto e te pede aprovação em cada etapa.
