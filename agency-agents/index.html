Monte uma agência inteira dentro do seu agente de IA

O Agency Agents é uma biblioteca grátis e open source com mais de 230 agentes de IA especialistas. Cada um tem personalidade, processo e entregas próprias. Você instala no Claude Code, Cursor, Codex, Gemini CLI e outros, e chama o especialista certo para cada tarefa.

01Pra que serve

  • Ter especialistas à mão sem montar prompt do zero: Frontend Developer, Backend Architect, SEO Specialist, Growth Hacker, Product Manager, Reality Checker e muitos outros.
  • Cobrir várias áreas: engenharia, design, marketing, vendas, tráfego pago, produto, gestão de projetos, testes, segurança, suporte, finanças, games, pesquisa e mais.
  • Trabalhar sozinho como se tivesse um time: um agente cria, outro revisa e outro testa.
  • Montar times prontos sugeridos pelo próprio projeto. Pra lançar um produto do zero: Frontend Developer, Backend Architect, Growth Hacker, Rapid Prototyper e Reality Checker. Pra uma campanha de marketing: Content Creator, Twitter Engager, Instagram Curator, Reddit Community Builder e Analytics Reporter.
  • Cuidar de anúncios pagos com um time só disso: Paid Media Auditor, Tracking & Measurement Specialist, PPC Campaign Strategist, Search Query Analyst, Ad Creative Strategist e Analytics Reporter.
  • Usar no agente que você já tem: Claude Code, Cursor, Codex, Gemini CLI, GitHub Copilot, Windsurf, OpenCode, Aider, Antigravity, Qwen Code, Kimi Code e outros.

02O que você precisa

  • Um agente de IA: Claude Code, Cursor, Codex, Gemini CLI…
  • O app Agency Agents (Windows, Mac ou Linux) ou, se preferir terminal, o repositório baixado no computador

03Passo a passo

  1. Jeito mais fácil, e o único com suporte oficial no Windows: baixe o app Agency Agents. Ele roda no Windows, Mac e Linux e se atualiza sozinho. Escolha a versão do seu sistema na página de downloads.
    https://github.com/msitarzewski/agency-agents-app/releases/latest
  2. Está no Mac e usa Homebrew? Dá pra instalar o app com um comando:
    brew install --cask msitarzewski/agency-agents/agency-agents
  3. Abra o app e navegue pela lista de agentes. Escolha os que quer e instale no Claude Code, Cursor, Codex, Gemini ou outro agente com um clique. Não precisa clonar nada nem rodar script.
  4. Prefere terminal (Mac ou Linux)? Com o repositório baixado no computador, entre na pasta dele e rode este comando. Ele instala todos os agentes no Claude Code. Pra outros agentes, troque claude-code por codex, cursor ou gemini-cli (nesse último, rode antes ./scripts/convert.sh --tool gemini-cli).
    ./scripts/install.sh --tool claude-code
  5. Não sabe qual comando usar? Rode o instalador sozinho, sem nada depois: ele vai perguntando o que você quer, passo a passo.
    ./scripts/install.sh
  6. Não quer os mais de 230? Primeiro veja a lista de equipes disponíveis:
    ./scripts/install.sh --list teams
  7. Depois instale só as equipes que interessam. Exemplo com engenharia e segurança:
    ./scripts/install.sh --tool claude-code --division engineering,security
  8. Ou escolha especialistas um por um pelo nome. Este exemplo do projeto instala só o Frontend Developer e o UI Designer no Cursor:
    ./scripts/install.sh --tool cursor --agent frontend-developer,ui-designer
  9. Agora é só chamar o especialista pelo nome no seu agente, como no exemplo do próprio projeto:
    Hey Claude, activate Frontend Developer mode and help me build a React component
  10. Também dá pra pedir de um jeito mais direto, citando o agente:
    Use the Frontend Developer agent to review this component.

05Antes de usar

  • A biblioteca é grátis e tem licença MIT: dá pra usar em projeto pessoal ou comercial. Mas o agente onde você instala (Claude Code, Cursor, Codex…) tem o custo e os limites dele.
  • Os scripts de terminal são .sh e o projeto não traz instruções de script pra Windows. No Windows, use o app.
  • Os agentes são instruções de especialista, não mágica: a IA continua podendo errar. Revise o que ela entregar, principalmente código e números.
  • No OpenCode só cabem uns 119 agentes; o resto é ignorado sem aviso. Instale por área (opção --division) em vez de tudo. No Aider, o texto completo tem cerca de 1 milhão de tokens: carregue só o agente que vai usar.
  • Os agentes são escritos em inglês. Peça "Responda em português" no fim do pedido.
  • Quanto menos agentes instalados, mais fácil achar o certo. Comece com 2 ou 3 equipes e adicione outras quando precisar.

Resumindo: baixa o app, instala os especialistas no agente que você já usa com um clique e chama cada um pelo nome quando precisar.
