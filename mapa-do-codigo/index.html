Veja qualquer projeto de código como um mapa que você clica

O Understand Anything é um complemento grátis pro seu agente de IA (Claude Code, Codex, Cursor, Copilot e outros). Ele lê o projeto inteiro e monta um mapa interativo com cada arquivo, função e ligação entre eles. Aí você clica num pedaço e lê o que ele faz, em vez de abrir arquivo por arquivo.

01Pra que serve

  • Entender rápido um código que você herdou ou acabou de baixar, sem ninguém pra explicar.
  • Ver o projeto dividido em camadas, cada uma com uma cor: dados, serviço, tela, utilitários. Assim você sabe onde fica cada coisa.
  • Clicar em qualquer pedaço do mapa e ler um resumo simples do que ele faz e com o que ele conversa, com tours guiados pela estrutura.
  • Perguntar pro próprio plugin como algo funciona, tipo "como funciona o pagamento?".
  • Antes de subir uma alteração, ver quais partes do sistema ela vai mexer.

02O que você precisa

  • Um agente de IA instalado: Claude Code, Codex, Cursor, Copilot, Gemini CLI…
  • A pasta do projeto que você quer entender, no seu computador
  • Node.js 18 ou mais novo, só se quiser abrir o mapa sem o agente

03Passo a passo

  1. Usa o Claude Code? Abra ele e cole esta linha pra adicionar a loja do plugin:
    /plugin marketplace add Egonex-AI/Understand-Anything
  2. Depois instale o plugin com esta outra linha. Se você usa outro agente, pule pro passo 3.
    /plugin install understand-anything
  3. Outros agentes. No Windows, abra o PowerShell (o terminal que já vem no Windows), cole a linha abaixo e digite o número do seu agente quando ele perguntar. No Mac, o Codex instala com: curl -fsSL https://raw.githubusercontent.com/Egonex-AI/Understand-Anything/main/install.sh | bash -s codex. No Copilot pelo terminal: copilot plugin install Egonex-AI/Understand-Anything:understand-anything-plugin. No Cursor ele aparece sozinho quando você clona o repositório. Se não aparecer, vá em Cursor Settings → Plugins e cole o link oficial.
    iwr -useb https://raw.githubusercontent.com/Egonex-AI/Understand-Anything/main/install.ps1 | iex
  4. Abra a pasta do projeto no seu agente e peça a análise. Vários agentes leem o código e montam o mapa. No Codex o comando começa com $ em vez de / ($understand). A primeira vez demora mais nos projetos grandes.
    /understand
  5. Abra o painel no navegador. É ali que fica o mapa: clique num pedaço pra ler o que ele faz, use a busca e siga os tours guiados.
    /understand-dashboard

05Antes de usar

  • O plugin é grátis, mas quem trabalha é o seu agente de IA. A primeira análise lê o projeto inteiro e pode gastar bastante do seu plano em projeto grande. As próximas só releem o que mudou e gastam bem menos.
  • Projeto enorme? Analise uma pasta por vez, por exemplo: /understand src/frontend.
  • Os resumos do painel saem em inglês por padrão, e o português não está na lista de idiomas (só inglês, chinês, japonês, coreano, russo e vietnamita). Pra ter as respostas em português, peça no /understand-chat, como no primeiro pedido acima.
  • Seu código é lido pela IA do agente que você usa. Se o projeto for sigiloso, o repositório explica como usar um modelo que roda no seu próprio computador (Ollama). O painel em si não manda nada pra fora.
  • Licença MIT: pode usar, mudar e até colocar num produto que você vende, desde que mantenha o aviso de licença original junto.

Resumindo: instala com um comando no agente que você já usa, roda /understand na pasta do projeto e clica no mapa pra entender qualquer código.
