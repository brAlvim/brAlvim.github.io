Coloque agentes de IA pra jogar Minecraft sozinhos

Este é o programa gratuito usado no teste em que 50 agentes de IA tentaram construir uma civilização no Minecraft. Você escreve um objetivo, liga o agente a um mundo e assiste a IA jogando como um jogador normal. Dá pra começar com um agente só ou montar um time.

01Pra que serve

  • Dar um objetivo por escrito e ver a IA andar, minerar, criar itens, construir, lutar e conversar sozinha no jogo.
  • Montar um time de agentes que trocam mensagens entre si e dividem o trabalho.
  • Parar e continuar depois: se você ligar o agente de novo com o mesmo nome, ele segue de onde parou.
  • Escolher quem joga: Claude, GPT, Gemini ou modelos do OpenRouter.

02O que você precisa

  • Node.js 22.19 ou mais novo (o programa que faz o projeto rodar)
  • Uma chave de acesso de uma empresa de IA (OpenAI, Anthropic, Google ou OpenRouter)
  • Um servidor de Minecraft. Se não tiver, o projeto traz um de teste, que precisa do Java 21
  • Minecraft Java 1.21.6, só se você quiser entrar no mundo pra assistir

03Passo a passo

  1. Abra o link oficial, clique no botão verde Code e depois em Download ZIP. Descompacte a pasta no seu computador. Instale também o Node.js 22.19 ou mais novo e, se for usar o servidor de teste, o Java 21.
    https://github.com/yc-software/minecraft-agent-harness
  2. Abra o terminal (a janela de comandos; no Windows, o PowerShell) dentro da pasta e instale o projeto.
    npm ci
  3. Crie o arquivo onde fica a sua chave. No Windows, se o comando der erro, duplique o arquivo .env.example na mão e renomeie a cópia pra .env. Depois abra o .env no Bloco de Notas e cole a chave da OpenAI logo depois do sinal de igual, na primeira linha de chave. O modelo padrão é o GPT-6.1 Terra, por isso a chave começa pela OpenAI.
    cp .env.example .env
  4. Ligue o servidor de teste e deixe essa janela aberta. Ele cria um mundo no seu computador, no endereço localhost:25565.
    npm run server
  5. Abra um segundo terminal na mesma pasta e ligue o agente com um objetivo. O que ele faz vai aparecendo na tela. Pra parar, aperte Ctrl+C.
    npm start -- --objective "Gather wood and build a small shelter near spawn"
  6. Pra assistir, abra o Minecraft 1.21.6 e entre no servidor abaixo. Pra falar com o agente, digite /tell Agent seguido da sua mensagem.
    localhost:25565

04Objetivos prontos pra colar no terminal

Primeira casa, com tempo limitadoPro primeiro teste: o agente para sozinho depois dos minutos que você escolher
npm start -- --duration [MINUTOS] --objective "Junte madeira e pedra e construa uma casa de [TAMANHO, EX.: 5 POR 5 BLOCOS] perto de onde você nasceu. Coloque uma cama, um baú e uma porta. Quando escurecer, fique dentro da casa até amanhecer."
Teste de coragemPra ver se uma personalidade ousada foge da cautela do experimento. O nome aceita até 16 letras, números ou _
npm start -- --name [NOME] --duration [MINUTOS] --personality "Corajoso e curioso. Prefere tentar e errar a ficar parado." --objective "Explore o mundo longe de onde você nasceu, encontre [O QUE PROCURAR, EX.: FERRO] e volte com pelo menos [QUANTIDADE]. Anote o que aprendeu a cada morte."
Mini civilização com 3 agentesTroque o conteúdo do arquivo examples/team.json por este texto, mude o objetivo e rode: npm start -- team examples/team.json. Aqui os agentes só conversam entre si e jogam, sem rodar comandos no seu computador
{
  "host": "localhost",
  "port": 25565,
  "model": "openai/gpt-6.1-terra",
  "objective": "Construam juntos [SEU OBJETIVO, EX.: UMA VILA COM TRÊS CASAS, UMA FAZENDA E UM CAMINHO ENTRE ELAS].",
  "durationMinutes": 20,
  "sandbox": "none",
  "sharedMachine": "none",
  "agents": [
    { "name": "Ada" },
    { "name": "Bram", "personality": "Corajoso, gosta de explorar e assumir riscos." },
    { "name": "Cleo", "personality": "Planejadora cuidadosa que anota tudo." }
  ]
}
Jogar com o Claude em vez do GPTTire o # da linha da Anthropic no arquivo .env e cole a sua chave nela. Pra ver os modelos disponíveis, rode: npx minecraft-agent models anthropic
npm start -- --model anthropic/claude-sonnet-4-6 --duration [MINUTOS] --objective "Faça uma vara de pescar e pesque [QUANTIDADE] peixes. Guarde tudo em um baú perto de [LUGAR] e me avise pelo chat quando terminar."

05Antes de usar

  • O programa é grátis (licença MIT), mas cada agente usa o modelo da sua chave. O projeto não informa quanto custa uma partida, então confira os preços na empresa da chave. Comece com 1 agente e use --duration, porque sem isso ele joga sem limite de tempo.
  • Segurança: por padrão, cada agente ganha um terminal próprio. Sem Docker (programa que isola o agente numa caixa separada) nem E2B (computador na nuvem), os comandos rodam no seu computador como se fosse você. Pra tirar esse acesso, acrescente --sandbox none ao comando.
  • Não espere uma civilização pronta. No teste original, a colônia nunca prosperou de verdade e foi ficando cada vez mais cautelosa. A graça é observar o que eles decidem.
  • É pra Minecraft Java. O projeto foi feito e testado na versão 1.21.6, com servidor Paper. Em servidor próprio que exige login, use --auth microsoft.
  • A documentação oficial não traz passos específicos pra Windows. Ver o mundo pelos olhos do agente (--vision) é experimental e exige instalar peças extras.

06Perguntas comuns

A IA consegue jogar Minecraft de verdade?

Consegue andar, minerar, criar itens, construir, lutar e conversar como um jogador normal. Mas jogar bem é outra história: no teste dos 50 agentes, 22 das 34 mortes aconteceram na primeira noite e a colônia nunca chegou a prosperar.

Por que os agentes ficaram com tanto medo?

A onda de mortes da primeira noite deixou os agentes mais cautelosos de vez. Muitas tarefas ambiciosas foram abandonadas e, nas noites seguintes, eles ficaram amontoados em abrigos. E morrer ali só fazia o agente perder o que carregava.

Dá pra ver mais experimentos assim?

Dá. A mesma página do experimento conta outros testes com jogos, como Bed Wars e Mindustry. E o projeto traz um exemplo pronto de Bed Wars, com regras e juiz, na pasta examples/bedwars.

Posso rodar os 50 agentes em casa?

O projeto já rodou com 50 agentes num mesmo servidor, mas o exemplo que vem pronto liga 3. Cada agente precisa de uma linha no arquivo do time, então comece pequeno.

Resumindo: baixa o projeto, cola a sua chave, liga o servidor de teste e escreve o objetivo. Depois é só entrar no mundo e ver o que a IA faz sozinha.
