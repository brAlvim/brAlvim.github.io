Transforme o Claude Code num time inteiro trabalhando pra você

O Ruflo é gratuito e de código aberto. Ele adiciona ao Claude Code mais de 100 agentes especializados que trabalham juntos, em grupo, e uma memória que guarda o que deu certo antes. Você pede em português e acompanha tudo num painel ao lado.

01Pra que serve

  • Dividir uma tarefa grande entre vários agentes especializados que trabalham juntos como um time.
  • Guardar na memória o que funcionou e consultar isso nas próximas tarefas. O projeto diz que os agentes aprendem com os acertos.
  • Acompanhar num painel, ao lado do Claude Code, o que cada agente está fazendo, quantos tokens (a medida de uso do Claude) gastou e quanto custou.
  • O projeto diz que corta de 30 a 50% dos tokens gastos.

02O que você precisa

  • Claude Code na versão 2.1.287 ou mais nova
  • Uma conta do Claude com plano que dê acesso ao Claude Code

03Passo a passo

  1. Atualize o Claude Code. O Ruflo só funciona da versão 2.1.287 em diante. Depois abra o Claude Code na pasta do seu projeto.
  2. Dentro do Claude Code, adicione a loja de extensões do Ruflo:
    /plugin marketplace add ruvnet/ruflo
  3. Instale a parte principal do Ruflo:
    /plugin install ruflo-core@ruflo
  4. Instale o painel de acompanhamento e a extensão que coloca os agentes trabalhando em time:
    /plugin install ruflo-console@ruflo
/plugin install ruflo-swarm@ruflo
  5. Recarregue as extensões e abra o painel do Ruflo:
    /reload-plugins
/ruflo
  6. Pronto. Agora é só pedir em português, como nos prompts abaixo, e acompanhar o andamento no painel.

04Prompts prontos pra colar no Claude Code

Começar uma missãoO uso principal: troque o objetivo pelo seu
Crie uma missão para [SEU OBJETIVO, ex.: montar uma página de vendas para o meu curso de confeitaria].
Divida em tarefas, diga quais agentes vão cuidar de cada parte e me mostre a missão e o status dela antes de começar.
Responda em português.
Time de revisãoPra conferir um projeto que já existe nesta pasta
Monte um time de agentes para revisar o projeto desta pasta.
Um procura erros, outro olha segurança e outro sugere melhorias no texto e na facilidade de uso para [PÚBLICO, ex.: clientes que compram pelo celular].
Junte tudo num relatório em português, do mais urgente para o menos urgente, sem mudar nenhum arquivo ainda.
Ensinar o que deu certoNo fim de uma tarefa que ficou boa
Guarde na memória do Ruflo o que funcionou nesta tarefa: [O QUE DEU CERTO, ex.: o tom do texto, a ordem das seções, o modelo de e-mail].
Na próxima vez que eu pedir [TIPO DE TAREFA], procure essa memória antes de começar e me diga o que vai reaproveitar.
Conferir o gastoDepois de rodar uma missão
Mostre no painel do Ruflo quantos tokens e quanto custou cada agente na missão [NOME DA MISSÃO].
Me diga qual parte gastou mais e o que dá pra fazer para gastar menos da próxima vez.

05Antes de usar

  • O Ruflo é gratuito (licença MIT), mas cada agente usa o seu plano do Claude. Muitos agentes ao mesmo tempo gastam o limite mais rápido. Acompanhe o custo no painel.
  • A economia de 30 a 50% de tokens e o aprendizado são promessas do próprio projeto. O resultado depende de como a memória está configurada e da qualidade do retorno que você dá.
  • Criar uma missão não quer dizer que o trabalho foi feito. Confira o resultado antes de usar. A animação do painel na página do projeto usa dados de exemplo.
  • As extensões extras (como a ruflo-mods) rodam com as permissões da sua conta, sem proteção. Leia o que fazem antes de instalar e só instale o que for usar.
  • Usa Codex ou outro assistente no Windows? O instalador com 'curl ... | bash' não roda no PowerShell. Use este no lugar: npx ruflo@latest init wizard

Resumindo: instala em 4 comandos dentro do Claude Code, abre o painel com /ruflo e pede em português o que o seu time de agentes deve fazer.
