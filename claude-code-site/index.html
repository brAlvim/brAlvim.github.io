Guia grátis em português

Descreva o site que você quer e a IA escreve o código

O Claude Code é uma IA que programa por você. Você conta em português o que quer, e ela planeja, escreve o código em vários arquivos e confere se funciona. Dá pra usar direto no navegador, em claude.ai/code, sem instalar nada no computador.

01Pra que serve

  • Criar um site do zero só descrevendo o que você quer: páginas, textos, seções e formulário de contato.
  • Mudar um site que já existe: trocar cores, incluir uma página nova, arrumar algo que quebrou.
  • Entender um projeto que já está pronto. Você não precisa explicar nada: ele lê os arquivos sozinho quando precisa.
  • Pedir uma coisa e ir fazer outra: no navegador, o trabalho continua mesmo se você fechar a aba.

02O que você precisa

  • Assinatura paga do Claude: Pro, Max ou Team (no Enterprise, com assento que inclui o Claude Code)
  • Uma conta no GitHub, o site onde o código do seu projeto fica guardado
  • Navegador no computador ou o app do Claude no celular (iOS ou Android)

03Passo a passo

  1. Pra começar um site novo, crie no GitHub um repositório vazio (é a pasta do seu projeto lá). Dê um nome, tipo meu-site, e clique em Create repository.
    https://github.com/new
  2. Abra o Claude Code no navegador e entre com a sua conta do Claude. Quando ele pedir pra conectar o GitHub, siga o aviso e aprove. Isso só precisa ser feito uma vez. Se aparecer a opção de instalar o app do Claude no GitHub e você quiser deixar pra depois, clique em Skip.
    https://claude.ai/code
  3. Se o seu repositório for privado, ele só aparece na lista depois que você instala o app do Claude no GitHub. É só abrir este link e escolher a sua conta:
    https://github.com/apps/claude/installations/new
  4. Clique no seletor de repositório, embaixo da caixa de texto, e escolha o que você criou. No controle de modo, escolha Plan: ele mostra o plano primeiro e só começa a mexer nos arquivos quando você aprovar.
  5. Escreva o que você quer e aperte Enter. O truque do reel vale aqui: divida o pedido em etapas numeradas (página inicial, depois serviços, depois contato). Use os prompts prontos aí embaixo.
  6. Quando ele terminar, clique no contador de mudanças (algo como +42 -18) pra ver tudo o que foi alterado. Pra pedir um ajuste numa linha, clique nela e escreva. Quando estiver do seu jeito, clique em Create PR, no topo dessa tela, pra levar as mudanças pro seu projeto no GitHub.

04Prompts prontos pra colar no Claude Code

Site de agência em etapasO pedido do reel: troque o que está entre colchetes pelo seu
Crie um site para a minha agência [NOME DA AGÊNCIA], que faz [O QUE A AGÊNCIA FAZ] em [CIDADE].
Faça em etapas, nesta ordem:
1. Página inicial com uma chamada forte, um resumo do que a gente faz e um botão para a página de contato.
2. Página de serviços com estes serviços, cada um com título, descrição curta e um ícone: [SERVIÇO 1], [SERVIÇO 2], [SERVIÇO 3].
3. Página de contato com formulário (nome, e-mail, mensagem), botão de WhatsApp para o número [SEU NÚMERO] e o endereço [ENDEREÇO].
O site tem que ficar bom no celular. Cores principais: [CORES]. Todos os textos em português.
No fim, confira se todos os links entre as páginas funcionam.
Página de vendas de um produtoPra quem vende um curso, serviço ou produto
Crie uma página de vendas para [NOME DO PRODUTO], que custa [PREÇO] e é para [PARA QUEM É].
1. Topo com o título, uma frase que mostra o resultado que a pessoa vai ter e um botão de compra que leva para [LINK DE PAGAMENTO].
2. Seção com 3 benefícios: [BENEFÍCIO 1], [BENEFÍCIO 2], [BENEFÍCIO 3].
3. Seção de perguntas frequentes com estas perguntas: [PERGUNTAS].
4. Rodapé com [SEU INSTAGRAM] e [SEU E-MAIL].
Antes de escrever, me mostre o plano em português e espere eu aprovar.
Ajustar o que ficou estranhoDepois que o site ficou pronto, na mesma conversa
Olhando o site que você fez, quero estas mudanças:
1. Na página inicial, troque o título para "[NOVO TÍTULO]" e deixe a fonte maior.
2. Na página de serviços, adicione o serviço [NOVO SERVIÇO] com a descrição: [DESCRIÇÃO].
3. Mude a cor dos botões para [COR].
Não mexa no resto. Quando terminar, me diga em português quais arquivos você mudou e confira se nada quebrou.
Entender um projeto que já existeQuando você pegou um site pronto e não sabe por onde começar
Me explique em português, como se eu nunca tivesse programado:
1. O que esse projeto faz.
2. Em quais arquivos ficam os textos de cada página.
3. Onde eu mudo as cores e o logotipo.
Não altere nada por enquanto, só me explique.

05Antes de usar

  • Não é de graça: no navegador, ele só funciona com plano pago (Pro, Max ou Team). Cada pedido conta no limite de uso do seu plano, junto com o que você usa no Claude normal. O computador na nuvem onde ele trabalha não cobra nada a mais.
  • Seja específico. "Arruma o site" dá resultado ruim. Diga qual página, o que está errado e como você quer que fique.
  • Fechar a aba não para o trabalho: ele continua até terminar a tarefa. Pra tirar uma conversa da lista, arquive ou apague pela barra lateral.
  • O guia oficial não explica como colocar o site no ar pra todo mundo ver. Isso é uma etapa a mais. Pergunte pro próprio Claude Code quais são as opções.
  • Prefere usar no seu computador? No Windows, abra o PowerShell e rode: irm https://claude.ai/install.ps1 | iex . Depois feche, abra um terminal novo e digite claude --version pra conferir. Assim ele usa as pastas do seu PC e não precisa do GitHub.

Resumindo: abre o claude.ai/code, conecta o GitHub, descreve o site em etapas numeradas e ele planeja, escreve e confere tudo pra você.
