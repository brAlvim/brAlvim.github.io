Faça o Claude Code criar animações limpas, sem resultado genérico

O Awesome AI Motion é uma biblioteca aberta com 637 técnicas de animação e 128 clipes de referência, feita pro Claude Code ler. Você escolhe um efeito e o Claude segue a ficha dele, com os ajustes já feitos, em vez de inventar uma animação do zero.

01Pra que serve

  • Criar animações pra vídeo, vídeo curto, infográfico e apresentação com um ponto de partida testado.
  • Consultar a ficha de cada efeito: o que ele faz, quando usar, quando evitar, ajustes recomendados, exemplos e prompts prontos.
  • Usar 11 receitas que juntam vários efeitos em sequência, como gancho de vídeo curto, antes e depois, história com dados e demonstração de produto.
  • Receber o resultado em três arquivos: vídeo (clip.mp4), GIF de prévia (preview.gif) e imagem de capa (poster.jpg).
  • Ver e comparar até quatro clipes no site, inclusive em câmera lenta, antes de escolher.

02O que você precisa

  • Claude Code ou Codex
  • Git, o programa que baixa a pasta do GitHub
  • Só pra gerar vídeo no seu computador: Node.js 20 ou mais novo, ffmpeg (programa que monta o vídeo) e Playwright com Chromium (um navegador que grava a animação)
  • Pra só olhar o site, ler as fichas e usar a skill, não precisa instalar esses programas de vídeo

03Passo a passo

  1. Abra o site, assista aos clipes e anote os efeitos de que gostou. Essa parte não precisa de instalação.
    https://gongnyang.github.io/awesome-ai-motion/
  2. Abra o terminal, a tela onde você digita comandos, e baixe a biblioteca. No Windows, pule pro prompt "Instalar no Windows" lá embaixo, porque os comandos oficiais são pra Mac e Linux.
    git clone https://github.com/gongnyang/awesome-ai-motion.git
cd awesome-ai-motion
  3. Ligue a pasta nas skills do Claude Code. Skill é um pacote de instruções que o Claude consulta. No Codex é igual, trocando o destino por ~/.codex/skills/.
    mkdir -p ~/.claude/skills
ln -s "$PWD" ~/.claude/skills/awesome-ai-motion
  4. Vai gerar vídeo no seu computador? Instale o que falta. Se já tiver o Playwright ou o Chromium, pode pular a linha correspondente. A última linha só confere se o ffmpeg está funcionando.
    npm install
npx playwright install chromium
ffmpeg -version
  5. Faça o primeiro teste. Depois abra a pasta .staging/my-first-motion e veja o clip.mp4, o preview.gif ou o poster.jpg.
    node scripts/render.mjs effects/mask-reveal \
  --embed --text "Make it move" --out .staging/my-first-motion
  6. Pronto. Abra o Claude Code e peça em português, como nos prompts abaixo. O guia oficial não indica nenhum comando especial pra chamar a skill: basta pedir que ele use a awesome-ai-motion.

05Antes de usar

  • Nem toda técnica vem com vídeo pronto: são 637 técnicas e 128 clipes de referência. As outras têm só a ficha, então o Claude precisa criar a animação a partir dela.
  • As instruções oficiais não falam de Windows. Os comandos são pra Mac e Linux, então, no Windows, confira o que o Claude Code vai fazer antes de aprovar.
  • O repositório não informa custo. A biblioteca é aberta, mas o uso do Claude Code ou do Codex segue as regras do plano que você tem.
  • Sempre use uma pasta própria pra salvar, como .staging/. Gerar um efeito sem indicar a pasta de saída sobrescreve os arquivos do exemplo original.
  • Parte do material está em coreano, como os guias por tipo de conteúdo (redes, vídeo, apresentação). Peça sempre a resposta em português.
  • O material original usa a licença MIT, que é bem livre. A biblioteca de animação GSAP e as fontes incluídas têm licenças próprias, e as fontes citadas nas fichas variam. O repositório não fala diretamente de uso comercial dos vídeos gerados, então confira as licenças antes de usar em cliente ou redistribuir arquivos.
  • Se você copiou a pasta em vez de ligar, ela não recebe as novidades sozinha: precisa atualizar a cópia quando a biblioteca mudar.

Resumindo: baixe a biblioteca, ligue nas skills do Claude Code e peça o efeito em português. Você sai com vídeo, GIF de prévia e imagem de capa.
