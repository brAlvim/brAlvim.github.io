Guia grátis em português

Faça vídeos animados só conversando com o Claude

O Remotion monta vídeos a partir de código, e você não precisa escrever esse código. Você pede em português, o Claude Code escreve, e você vê o vídeo pronto no navegador. As skills oficiais do Remotion ensinam ao Claude o jeito certo de montar cada vídeo. Por isso o resultado sai no mesmo padrão toda vez.

01Pra que serve

  • Criar reels e vídeos animados (títulos, textos que aparecem, gráficos, mapas) descrevendo o que você quer.
  • Pôr narração e música como arquivo de áudio, com o volume subindo e descendo em cada momento do vídeo.
  • Repetir o mesmo estilo em todos os vídeos: as skills são instruções fixas que o Claude segue sempre que precisa.
  • Ver a prévia no navegador antes de gerar o arquivo final do vídeo.

02O que você precisa

  • Node.js (o programa que roda os comandos do Remotion), baixado em nodejs.org
  • Claude Code instalado (a maioria dos agentes de código pede assinatura paga)
  • O terminal do computador (no Windows, o PowerShell)

03Passo a passo

  1. Instale o Node.js pelo site oficial e o Claude Code. Depois abra o terminal (no Windows, procure PowerShell no menu Iniciar; no Mac, procure Terminal).
    https://nodejs.org
  2. Crie um projeto de vídeo em branco. Ele fica numa pasta chamada my-video.
    npx create-video --yes --blank my-video
  3. Entre na pasta e instale as skills oficiais do Remotion. Elas ensinam ao Claude as boas práticas para montar os vídeos. Primeiro rode cd my-video, depois:
    npx remotion skills add
  4. Abra a prévia do vídeo. Deixe essa janela do terminal aberta enquanto você trabalha.
    npm run dev
  5. Abra outra janela do terminal, entre na pasta de novo (cd my-video) e chame o Claude Code. Agora é só pedir o vídeo, como nos prompts abaixo.
    claude
  6. Se quiser chamar uma skill específica, escreva a barra e o nome dela no começo da mensagem. A /remotion-best-practices reúne todas, e a /remotion-render gera o arquivo final do vídeo.
    /remotion-best-practices

05Antes de usar

  • O Remotion é grátis para pessoa física e empresa de até 3 pessoas. Empresa maior paga licença. Na dúvida, pergunte pro Claude com /remotion-license.
  • O Claude Code não é grátis: a maioria dos agentes de código pede assinatura paga. Os vídeos são ilimitados, mas o uso do Claude conta no seu plano.
  • Sempre confira na prévia antes de gerar o vídeo final. A IA pode errar o tempo de uma cena ou o tamanho de um texto, e aí é só pedir o ajuste.
  • A janela com npm run dev precisa ficar aberta para a prévia funcionar. Fechou sem querer? Entre na pasta e rode o comando de novo.
  • Música e voz precisam ser suas ou ter licença de uso. O Remotion não resolve direito autoral do áudio.

Resumindo: cria o projeto com um comando, instala as skills, abre o Claude Code e pede o vídeo em português. As skills fazem cada vídeo sair no mesmo padrão.
