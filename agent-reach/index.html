Guia grátis em português

Faça o seu Claude ler e pesquisar na internet inteira, de graça

O Agent Reach é uma ferramenta grátis e de código aberto, com quase 98 mil estrelas no GitHub. Você cola uma linha no Claude Code e ele passa a ler tweets, posts do Reddit, vídeos do YouTube, projetos do GitHub, qualquer página e qualquer feed RSS. Não tem mensalidade nem chave paga de nenhum site.

01Pra que serve

  • Resumir um vídeo do YouTube sem você assistir. O Claude lê a legenda e te conta o que foi dito.
  • Ler um tweet, um post do Reddit ou qualquer página que você mandar o link, e pesquisar assuntos nessas redes.
  • Explicar o que faz um projeto do GitHub antes de você instalar.
  • Acompanhar qualquer feed RSS (blogs, notícias, podcasts) sem configurar nada.
  • Os seus logins ficam salvos só no seu computador. Nada é enviado pra fora.

02O que você precisa

  • Claude Code (o programa em que o Claude mexe no seu computador). Também serve no Cursor e no OpenClaw.
  • Python 3.10 ou mais novo (o programa que faz a ferramenta rodar). O próprio Claude confere se você tem.
  • Chrome, se quiser ligar o Reddit, o Instagram ou o Facebook.
  • Uma conta no X (Twitter) e no Reddit, se quiser ler essas duas redes.

03Passo a passo

  1. Abra o Claude Code e cole esta linha, do jeito que está. É a versão segura: ele confere tudo primeiro e não muda nada no seu computador sem perguntar.
    Safely check and install Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
  2. O Claude vai mostrar o que falta e pedir permissão antes de instalar. Leia e aprove. No Windows, se ele disser que o python3 aponta pra WindowsApps, é só um atalho da Microsoft Store: peça pra ele usar o comando py -3 no lugar.
  3. Ele pergunta quais redes você quer ligar. YouTube, GitHub público, páginas e RSS já funcionam sem nada. Pra ligar o Reddit, basta estar logado no reddit.com no Chrome.
  4. Pra ligar o X (Twitter): entre no x.com, instale a extensão Cookie-Editor no navegador, clique em Export e depois em Header String. Cole o que copiou quando o Claude pedir. O cookie é o arquivinho que mantém você logado, e fica guardado só no seu computador.
  5. Pra ver o que já está funcionando e o que falta arrumar, peça pro Claude rodar:
    agent-reach doctor
  6. De tempos em tempos, atualize colando esta linha no Claude Code:
    Update Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md

05Antes de usar

  • Grátis de verdade no seu computador. O único custo possível é um proxy (um intermediário de conexão) de mais ou menos US$ 1 por mês, e só se você rodar num servidor ou numa rede que bloqueia o Reddit ou o X.
  • X (Twitter), Reddit, Instagram e Facebook só funcionam com você logado. Usar o login assim pode fazer a rede limitar ou bloquear a conta: o próprio projeto recomenda usar uma conta secundária, não a principal.
  • O cookie dá acesso total à sua conta. Nunca mande pra ninguém nem cole em outro site.
  • O Reddit não tem caminho sem login. Se você não estiver logado no Chrome, ele não vai funcionar.
  • Instale só pela linha deste guia. Existe um pacote com o mesmo nome no PyPI (uma loja de programas em Python) que não é este projeto.
  • O projeto não tem moeda, token nem carteira. Mensagem pedindo pra conectar carteira em nome dele é golpe.
  • Licença MIT: pode usar à vontade, inclusive em trabalho.

Resumindo: cola uma linha no Claude Code, aprova o que ele pedir e o Claude passa a ler YouTube, GitHub, Reddit, X e qualquer site, sem pagar nada.
