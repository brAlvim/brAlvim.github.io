Guia grátis em português

Faça uma animação 3D só descrevendo o que você quer

Você conta a cena em português e o Claude escreve um script em Python, um arquivo de instruções que monta tudo no Blender, o programa grátis de 3D. Aqui não tem vídeo gerado por IA: a animação é 3D de verdade, e dá pra mudar cada detalhe só pedindo.

01Pra que serve

  • Criar uma animação 3D sem aprender os menus do Blender: você descreve, o Claude monta a cena.
  • Ajustar qualquer coisa só pedindo. Tudo que muda num botão do Blender também muda pelo script: cor, luz, câmera, velocidade.
  • Testar uma imagem antes de fazer o vídeo inteiro, pra não perder tempo com uma cena errada.
  • Sair com um arquivo de vídeo pronto: o Blender cria as imagens e o FFmpeg, um programa que trabalha com vídeo, junta tudo.
  • O que você cria com o Blender é seu, inclusive pra uso comercial.

02O que você precisa

  • Windows 10 (versão 1809 ou mais nova) ou macOS 13 ou mais novo
  • Computador com pelo menos 8 GB de memória RAM (o Blender recomenda 32 GB)
  • Blender instalado (grátis)
  • FFmpeg instalado
  • Conta paga do Claude: Pro, Max, Ultra, Team, Enterprise ou Console. O plano grátis não inclui o Claude Code
  • No Windows, o Git for Windows é recomendado (git-scm.com/downloads/win)

03Passo a passo

  1. Baixe o Blender na página oficial e instale como qualquer programa. Você não vai precisar mexer nele, mas ele precisa estar no computador.
    https://www.blender.org/download/
  2. Baixe o FFmpeg. O site oficial manda pra versões prontas feitas por terceiros. No Windows, use o link abaixo. No Mac, use evermeet.cx/ffmpeg.
    https://www.gyan.dev/ffmpeg/builds/
  3. No Windows, instale o Claude Code. Abra o PowerShell, a janela de comandos do Windows, cole a linha abaixo e aperte Enter.
    irm https://claude.ai/install.ps1 | iex
  4. No Mac, faça o mesmo no app Terminal, com esta linha. Depois, no Windows ou no Mac, abra uma janela nova e digite claude --version: se aparecer um número, deu certo.
    curl -fsSL https://claude.ai/install.sh | bash
  5. Crie uma pasta vazia pra animação. Na janela de comandos, entre nela com cd e o caminho da pasta. Depois digite o comando abaixo. Na primeira vez, o navegador abre pra você entrar na sua conta.
    claude
  6. Escolha o modelo Opus com o comando abaixo. Depois é só colar o primeiro prompt daqui de baixo. Quando o Claude pedir permissão pra fazer algo, leia e escolha Yes.
    /model opus

05Antes de usar

  • O Claude Code exige plano pago, e cada pedido gasta o limite de uso da sua conta. Pedidos e ajustes demais podem esgotar esse limite.
  • O Claude roda comandos no seu computador. Trabalhe numa pasta só pra isso e leia o que ele vai fazer antes de aprovar.
  • Mac: o Blender 5.0 ou mais novo só funciona em Mac com chip Apple Silicon e macOS 13 ou mais novo.
  • Criar as imagens do vídeo usa bastante o computador e pode demorar, principalmente em máquina mais simples. Por isso, teste uma imagem primeiro.
  • A primeira versão raramente sai perfeita. Conte com algumas rodadas de ajuste, principalmente em personagens e movimentos mais complicados.

Resumindo: instala o Blender, o FFmpeg e o Claude Code, descreve a cena em português e ajusta pedindo até o vídeo ficar do seu jeito.
