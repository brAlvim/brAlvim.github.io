Faça o Claude Code responder com menos palavra e gastar menos

O Caveman (homem das cavernas, em inglês) é grátis e open source. Ele faz o seu agente de IA ir direto ao ponto: resposta primeiro, sem textão em volta. Cada palavra é token (o pedaço de texto que a IA cobra), então resposta curta gasta menos. No exemplo do próprio projeto, a mesma correção caiu de 63 pra 20 tokens.

01Pra que serve

  • Receber a correção sem o textão em volta. A resposta vem primeiro e é curta.
  • Gastar menos token por conversa, pra durar mais no seu plano ou pagar menos.
  • O código, os comandos, os caminhos de arquivo e as mensagens de erro continuam exatamente iguais. Só o texto em volta encolhe.
  • Avisos de segurança e de ações que não têm volta continuam com frase completa.
  • Funciona no Claude Code e em mais de 30 agentes, como Codex, Gemini CLI e OpenCode.

02O que você precisa

  • Claude Code instalado (o agente de IA que roda no terminal)
  • Pra ligar em outros agentes pelo instalador geral: Node.js 22.13 ou mais novo (o programa que roda o instalador)

03Passo a passo

  1. Abra o terminal. No Windows, é o PowerShell: aperte a tecla Windows, digite PowerShell e abra. Cole este comando. São os dois comandos do vídeo, juntos numa linha só: o primeiro adiciona a loja do Caveman e o segundo instala.
    claude plugin marketplace add JuliusBrussee/caveman && claude plugin install caveman@caveman
  2. Se preferir instalar de dentro do Claude Code, digite estas duas linhas lá, uma de cada vez:
    /plugin marketplace add JuliusBrussee/caveman
/plugin install caveman@caveman
  3. Abra o Claude Code normalmente. O Caveman já liga sozinho em toda conversa. Pra conferir se está ativo, digite:
    /caveman status
  4. Escolha o quanto quer encurtar. /caveman é o padrão. /ultracave é ainda mais seco. /megacave responde em chinês clássico, então serve mais como curiosidade. Pra desligar, use /caveman off ou escreva "stop caveman". Pra ver todos os modos e comandos, use /caveman-help.
    /caveman off
  5. Usa outro agente, como Codex ou Gemini CLI? Este instalador funciona no Windows, no Mac e no Linux. Ele precisa do Node.js 22.13 ou mais novo.
    npx @caveman-ai/cli@latest
  6. Não gostou? Este comando desinstala tudo:
    npx -y github:JuliusBrussee/caveman -- --uninstall

04Pedidos prontos pra usar com o Caveman ligado

Corrigir um erro sem textãoO uso do dia a dia: cole o erro e receba só a causa e a correção
Quando eu [O QUE VOCÊ FAZ, ex.: clico em salvar], aparece este erro:
[COLE O ERRO AQUI]
O arquivo é [NOME DO ARQUIVO]. Me diga a causa em uma linha e já aplique a correção. Responda em português.
Revisar antes de salvarDepois que o agente mexeu no seu projeto. Cada problema vem numa linha, com a linha do arquivo, a gravidade e a correção
/caveman-review
Encolher o arquivo de instruçõesSe você tem um arquivo de instruções grande, que o agente lê em toda conversa. O Caveman guarda uma cópia do original
/caveman-compress [NOME DO ARQUIVO, ex.: CLAUDE.md]
Pedir uma explicação completaQuando você quer entender de verdade e o texto curto não basta
stop caveman
Agora me explique com calma, em português e sem pressa, [O QUE VOCÊ QUER ENTENDER, ex.: por que esse erro acontecia]. Use um exemplo simples. Depois disso pode voltar ao modo curto com /caveman.

05Antes de usar

  • Veja como você paga antes de instalar. As regras do Caveman custam uns 1.160 tokens a mais na entrada de cada conversa. Se você paga por pedido, como no GitHub Copilot, resposta mais curta não economiza nada.
  • Os números de economia são medidos pelo próprio projeto. Alguns testes ainda nem foram feitos. Num deles, com páginas da web, não houve economia nenhuma.
  • Ele vem coletando dados de uso ligado de fábrica. Pra desligar, rode no terminal: caveman telemetry off
  • O modo Auto escolhe sozinho uma IA mais barata ou mais forte pra cada pedido. Ele pede uma conta grátis e manda os seus pedidos recentes pro servidor do Caveman. Pra desligar: caveman off routing
  • O /caveman-compress manda o arquivo pra IA que você usa. Não use em arquivo com senha ou dado sensível.
  • Resposta curta demais pode deixar passar o porquê das coisas. Quando estiver aprendendo, desligue com /caveman off.
  • A licença é Apache 2.0 no repositório inteiro: dá pra usar, ler o código, fazer fork e publicar. Só o nome Caveman e o logo da pedra são marca registrada do criador.

Resumindo: um comando no terminal, e o seu agente para de enrolar e responde só o que importa. Antes de instalar, só confira como você paga.
