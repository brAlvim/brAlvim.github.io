Faça os prompts da sua IA melhorarem sozinhos

O DSPy é gratuito e de código aberto. Você mostra exemplos do que quer e diz como dar uma nota pra cada resposta. Ele testa versões diferentes do prompt, lê onde a IA errou e fica com a versão que tirou a melhor nota.

01Pra que serve

  • Parar de ajustar prompt na mão: quem testa e reescreve é o otimizador, seguindo a sua nota.
  • Melhorar uma tarefa que se repete, como separar chamados de suporte por urgência ou tirar nome e data de um e-mail.
  • Fazer um modelo mais barato render mais. No tutorial oficial, a nota de um modelo pequeno subiu de 78,1% para 90,1%, passando os 82,4% de um modelo maior sem otimização.
  • Trocar de serviço de IA sem recomeçar: funciona com OpenAI, Claude, Gemini e também com modelos rodando no seu computador pelo Ollama.
  • Guardar o prompt vencedor num arquivo e usar de novo quando quiser.

02O que você precisa

  • Python 3.10 ou mais novo (programa que roda o DSPy). Use até o 3.14: do 3.15 em diante, o GEPA não vem instalado
  • Uma chave de acesso de um serviço de IA (OpenAI, Anthropic, Google) ou o Ollama no seu computador, que não pede chave
  • Exemplos reais da sua tarefa, com a resposta certa
  • Uma regra clara pra dar nota de 0 a 1 em cada resposta

03Passo a passo

  1. Confira se você tem o Python 3.10 ou mais novo. Se não tiver, baixe em python.org. Depois abra o terminal: no Windows, o PowerShell; no Mac, o Terminal.
  2. Instale o DSPy com este comando:
    pip install dspy
  3. Crie um arquivo .py e diga qual IA vai usar. Troque YOUR_OPENAI_API_KEY pela sua chave e não mostre esse arquivo pra ninguém. Outros nomes que a documentação cita: anthropic/claude-sonnet-4-5-20250929, gemini/gemini-2.5-pro e ollama_chat/llama3.2:1b (no seu computador, sem chave). Modelos mudam, então confira o nome antes de usar.
    import dspy

lm = dspy.LM("openai/gpt-5-nano", api_key="YOUR_OPENAI_API_KEY")

dspy.configure(lm=lm)
  4. Descreva a tarefa: o que entra e o que sai. Você não escreve o prompt, só isso. Neste exemplo oficial, entra um e-mail e saem o nome e a data do evento.
    class ExtractEvent(dspy.Signature):
    """Extract event details from an email."""
    email: str = dspy.InputField()
    event_name: str = dspy.OutputField()
    date: str = dspy.OutputField()

extract = dspy.Predict(ExtractEvent)
  5. Escreva a regra da nota. É ela que guia tudo. Neste exemplo oficial, um robô escreve haicais (poemas curtos): a nota é 0 se o poema repete o nome da estação do ano e 1 se não repete. O texto em feedback explica o erro, e o otimizador usa isso pra reescrever o prompt.
    def haiku_score_gepa(example, prediction, trace=None, pred_name=None, pred_trace=None):
    """
    Penalize verbatim use of the input season string.
    A haiku should evoke the season through imagery, not name it
    directly.
    """
    text = prediction.haiku.lower()
    if example.season.strip().lower() in text:
        return dspy.Prediction(
            score=0.0,
            feedback="Don't reference the input season verbatim."
        )
    return dspy.Prediction(score=1.0, feedback=None)
  6. Rode a melhoria e salve o resultado. Troque haiku_bot pelo seu programa, haiku_metric pela sua função de nota, train pelos exemplos de treino e val pelos exemplos de conferência. O modo light testa cerca de seis versões do prompt. Depois é só esperar.
    reflection_lm = dspy.LM("openai/gpt-5.4")

optimizer = dspy.GEPA(
    metric=haiku_metric,
    reflection_lm=reflection_lm,
    auto="light",
    num_threads=2,
)

optimized_haiku_bot = optimizer.compile(haiku_bot, trainset=train, valset=val)

optimized_haiku_bot.save("haiku_bot.json")

05Antes de usar

  • Custa dinheiro: cada teste chama a IA várias vezes, e quem cobra é o serviço de IA. O site oficial mostra uma rodada ilustrativa de US$ 2,18 com 200 exemplos, mas isso é só um exemplo. A documentação não dá uma estimativa geral, então comece pelo modo light e com poucos exemplos.
  • O DSPy em si é grátis (licença MIT), mas exige escrever Python. Se você não programa, peça pro seu assistente de código montar, como nos pedidos acima.
  • A nota manda em tudo. Se a regra for ruim, ele vai otimizar a coisa errada. Teste a regra à mão antes.
  • Guarde um grupo de exemplos fora da melhoria pra conferir no final. Sem exemplos de conferência, o prompt pode ficar bom só nos casos que ele já viu.
  • Se aparecer erro de limite de uso do serviço de IA, diminua o num_threads.
  • O arquivo salvo não guarda a sua chave nem qual IA você usou: configure de novo ao carregar. E, se salvar o programa inteiro numa pasta, só abra pastas de quem você confia, porque ela traz código que roda no seu computador.

Resumindo: instala com um comando, você dá os exemplos e a regra da nota, e o DSPy testa e guarda o prompt que tirou a melhor nota.
