Ganhe um time inteiro que revisa, testa e entrega o seu projeto

O gstack é um pacote grátis de comandos pro Claude Code. Cada comando faz o papel de um especialista: alguém que questiona a sua ideia, um designer, um gerente de engenharia, um testador e quem cuida da entrega. Você digita /nome-do-comando e ele trabalha no seu projeto.

01Pra que serve

  • Questionar a sua ideia antes de começar: o /office-hours faz seis perguntas difíceis, discorda quando precisa e escreve um documento do projeto que os outros comandos usam.
  • Revisar o plano inteiro com um comando só: o /autoplan passa pelo olhar de dono, de design e de engenharia, um depois do outro.
  • Achar erros antes de quem usa achar: o /review procura os bugs que passam nos testes e quebram depois, e já conserta os óbvios.
  • Testar como uma pessoa de verdade: o /qa abre um navegador real, clica no seu site, reproduz os erros e corrige.
  • Entregar: o /ship roda os testes, confere a documentação e envia a mudança pro GitHub pronta pra ser aprovada.

02O que você precisa

  • Claude Code instalado
  • Git (programa que guarda as versões do código): git-scm.com
  • Bun versão 1.4.2 ou mais nova (programa que roda o gstack): bun.sh
  • No Windows: Windows 11, Node.js (nodejs.org) e o Git Bash, que vem junto com o Git (ou o WSL)
  • No Mac: funciona tudo. O navegador Aside (macOS 15+) é recomendado, mas não é obrigatório

03Passo a passo

  1. Instale o Git, o Bun e, se for Windows, também o Node.js, pelos sites oficiais. No Windows, use o Git Bash (vem com o Git) pra rodar o Claude Code.
  2. Abra o Claude Code e cole este pedido, exatamente como está. O próprio Claude baixa e instala tudo (leva uns 30 segundos):
    Install gstack: run git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack && cd ~/.claude/skills/gstack && ./setup then add a "gstack" section to CLAUDE.md that says to use the /browse skill from gstack for all web browsing and never use mcp__claude-in-chrome__* tools. Claude Code lists the installed skills itself, so the section needs no skill list. Then ask the user if they also want to add gstack to the current project so teammates get it.
  3. No fim, o Claude pergunta se quer colocar o gstack também no projeto atual, pra quem trabalha com você receber junto. Se você trabalha sozinho, pode responder que não.
  4. Comece pelo /office-hours e conte o que você está construindo. Depois teste o /review numa mudança e o /qa no endereço do seu site. O próprio criador diz: pare aí e veja se é pra você.
  5. Pra atualizar, digite no Claude Code:
    /gstack-upgrade
  6. No Windows sem o Modo de Desenvolvedor ligado, depois de cada atualização rode isto no Git Bash pra os comandos ficarem iguais aos da versão nova:
    cd ~/.claude/skills/gstack && ./setup

05Antes de usar

  • O gstack é grátis e de licença MIT (pode usar à vontade). O trabalho é feito pelo Claude Code, então quem paga o uso é o seu plano do Claude Code.
  • O /ship envia as mudanças pro GitHub. Só use quando já revisou e quer mesmo entregar.
  • O /qa e o /review consertam coisas sozinhos. Leia o que ele mudou antes de seguir.
  • Por padrão, algumas revisões mandam o seu código pra uma segunda opinião (Codex ou Claude Code, na sua própria conta). Pra desligar: gstack-config set codex_reviews disabled. Estatísticas de uso vêm desligadas.
  • No Windows 11 com o Controle Inteligente de Aplicativos (Smart App Control) ligado, os programas do gstack não abrem e aparece "Permission denied". A saída é usar o WSL ou desligar essa proteção.
  • É feito pra quem está construindo um app ou site com o Claude Code. São dezenas de comandos: não tente aprender todos. Comece pelos quatro do passo 4.

Resumindo: cola um pedido no Claude Code, ele instala sozinho e você passa a ter um time que questiona a ideia, revisa, testa e entrega o seu projeto, de graça.
