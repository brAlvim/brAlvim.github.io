Transforme um PDF numa apresentação de PowerPoint editável

O PPT Master é open source: você pede no chat do seu agente de IA e ele analisa o conteúdo, monta o design e exporta um .pptx de verdade, com formas, gráficos e tabelas que continuam editáveis.

Repositório oficial no GitHub ↗

Pra que serve

  • Transformar PDF, Word, texto ou um tema numa apresentação pronta.
  • Sair com um .pptx editável de verdade (não uma imagem achatada), com gráficos baseados nos dados.
  • Usar o modelo de slides da sua empresa.
  • Adicionar transições, animações e até narração a partir das notas do apresentador.

O que você precisa

  • Python 3.10+
  • Um agente de IA (o autor recomenda o Claude Code)
  • Assinatura ou chave da IA que você usar
  • Git (opcional)

Passo a passo

  1. Instale o Python 3.10 ou mais novo em python.org. No Windows, marque "Add Python to PATH" na instalação.
  2. Baixe o projeto. Com Git:
    git clone https://github.com/hugohe3/ppt-master.git cd ppt-master
  3. Sem Git: na página do GitHub, clique em Code → Download ZIP e descompacte. Depois, dentro da pasta, instale as dependências:
    pip install -r requirements.txt
  4. Abra a pasta no seu agente (Claude Code, Cursor, Copilot…) e peça pelo chat, como nos prompts abaixo.
  5. Usa Claude Code? Dá pra instalar como plugin, sem baixar nada:
    /plugin marketplace add hugohe3/ppt-master

Antes de usar

  • O PPT Master é grátis, mas a IA que roda por trás não: o uso do Claude, GPT ou Gemini segue o seu plano.
  • No Windows, se o comando python não funcionar, siga o guia de instalação para Windows no repositório.
  • Revise números e gráficos antes de apresentar: a IA monta a partir do documento, mas pode errar.

Resumindo: Python, uma pasta baixada e um pedido no chat. O PowerPoint sai pronto e você continua editando como qualquer outro.
